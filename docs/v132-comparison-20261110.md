## Deliberate adaptations and exclusions

- No paid-license activation, device binding, countdown, payment/Telegram links, or external license API is imported. This project previously removed its license gate; copying the reference gate would disable the user's app behind somebody else's license server. Its updater endpoint/key are also not imported.
- No redesign from the reference is imported. Keep the approved neutral shell, sidebar, row profiles and full horizontal rounded switcher. Sidebar scroll accommodates the extra entries at short window heights.
- No changes to service document styles, branding or native clipboard APIs. The reference hides Gemini branding with a MutationObserver; that violates the existing project scope.
- Do not import `Response.prototype.blob` overrides or the ChatGPT click-capture handler that cancels a Download click and guesses the largest image. Those are invasive workarounds, not evidence of a fix for the existing intermittent native incident. Native downloads remain on the current shared path.
- Do not replace the current ordered command queue, resize backpressure, preload lease cancellation, controller setup rollback or failure state tracking with the reference's older manager. It has a fixed ten-view cache and different folder ownership. Its account-wide removal logic is not compatible with this branch's linked-session deletion protection.
- Storyboard/TTS are explicit shortcuts through the existing navigation path, not additional competing WebViews or per-page redirect polling. If login lands at the service home, click the shortcut again. Automatic post-login redirect/resume from the reference is not imported. Gemini content bookmarks provide an explicit persistent return target.
- Gemini/Suno bulk creation works, but auto-login selectors are **not verified**. Their batch results explicitly say to open the profile and sign in; no unknown-page auto-click routine is added.
- Prompt data uses a separate `prompt-library.json` file; no import of another application's prompt data or profile directories is attempted. Reference prompt reads silently filter bad records/return empty on errors, and mutations have no storage lock; those weaknesses are not copied.

## Validation

- `tests/manual/v132-features.mjs`: Chromium integration with mocked IPC passed CRUD, detail, pin/color, search, copy success response, save failure, load failure/retry, delete cancellation, dialog focus/inert, narrow 760×620 layout and Gemini/Suno/Flow navigation plus exact tool targets.
- Browser test mocks native storage and clipboard. It does not verify native file replacement, Windows permission prompts, authenticated service availability, Gemini TTS generation or Suno downloads.
- Native Windows compilation/installer is checked by the PR packaging workflow; no scenario tests are added to CI or the installed executable.
- The existing intermittent Copy/Download incident is not reproduced or claimed resolved by this integration. No affected Windows profile/log is available in this environment.
